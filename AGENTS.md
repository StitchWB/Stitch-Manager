# Правила репо для агентов

Публичный репо (open-core, Zone-1) — источник правды для клиента и общего рантайма.

## Зоны исходников: правим ЗДЕСЬ

- Zone-1: `src/**`, `extension/**`, `bridge/**`, `eslint-plugin-ui-kit/**`,
  `python/stitch_backend/**`, `python/stitch_plugin_tools/**`, часть
  `python/autoreg/**`, корневые `README.md`/`package.json`/конфиги. Правки —
  обычным PR в `main`; приватный хаб подтянет их ночным sync, дублировать
  правку в хабе не нужно.
- Zone-2/3 (методы провайдеров, captcha, приватный сервер, research) сюда не
  попадают и здесь недоступны — не ищи и не добавляй их.

## Синхронизация из хаба

Дрейф, накопленный хабом, приезжает PR'ами вида
`chore(sync): mirror Zone-1 from hub (catch-up …)`. Это штатный catch-up,
трогать такие PR при обычной работе не нужно.
