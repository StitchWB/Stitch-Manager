Stripe Filler — Test Forms

These forms simulate various Stripe checkout layouts (different locales, attribute styles). Use the Stitch Toolkit extension → Stripe Filler → Detect or Fill on this page to verify field discovery and filling.

Form A: Standard Stripe IDs (English)

Uses exact Stripe element IDs like cardNumber, cardExpiry, etc.

Form B: French localized (aria-label + label)

Simulates Stripe checkout rendered in French. No IDs, only aria-label and <label> text.

Form C: German localized (data-testid + placeholder)

Uses data-testid and German placeholder. No standard IDs or autocomplete.

Form D: Minimal / Edge cases

Very minimal markup. Tests fallback label-matching and fuzzy matching.
